## 必要なもの

- 現行Gatewayアプリは macOS 14 以上。
- Chrome拡張は Google Chrome 116 以上。
- `abg` CLIを実行できるターミナル。
- 開発ビルドでは Xcode 16 以上、`mise`、Node.js、pnpm。

## macOSアプリとCLI

Homebrewからインストールできます。

```bash
brew tap arcmanagement/agent-browser-gateway https://github.com/arcmanagement/agent-browser-gateway
brew install --cask agent-browser-gateway
```

[download page](/#download) から現在のDMGを取得し、SHA-256 checksumを確認してから手動インストールすることもできます。
インストール後、アプリを一度起動してメニューバーにアイコンが出ることを確認します。

CLIから接続を確認します。

```bash
abg status
```

`abg` が `PATH` にない場合はrelease artifact内のCLIを配置するか、Homebrew caskからインストールします。

## Windows

対象releaseの `microsoft/winget-pkgs` PR がmergeされたあと、WinGetからインストールできます。

```powershell
winget install --id ArcManagement.AgentBrowserGateway --source winget
```

WinGetに現在のreleaseが反映されるまでは、[download page](/#download) からWindows x64 setup ZIPを取得し、
展開して `AgentBrowserGatewaySetup.exe` を実行します。非GUI payload ZIPには scripted install 用の
`Install-AgentBrowserGateway.ps1` も含まれます。

## ブラウザー拡張

通常利用ではChrome Web Storeから Agent Browser Gateway をインストールします。ローカル開発では
repositoryで拡張をbuildし、`extension/dist/` をunpacked extensionとして読み込みます。

incognito windowで使う場合は、拡張の詳細画面で **Allow in incognito** を有効にします。通常windowだけで
使う場合、この設定は不要です。

## エージェントスキル

GatewayとCLIを用意したあと、Claude CodeとCodex向けのskillをインストールまたは更新します。

```bash
abg install-skill --target both
```

片方だけ入れる場合は `--target claude` または `--target codex` を使います。

## 開発版アプリ

開発版は別のメニューバーアプリとして port `8766` で動き、ローカル状態も分離します。

```bash
CONFIG=debug APP_VARIANT=dev ./build-app.sh
open "Agent Browser Gateway Dev.app"
ABG_PORT=8766 .build/debug/abg status
```

productionのuser pluginは `~/.abg/plugins/`、`ABG_PORT=8766` のdev実行では `~/.abg-dev/plugins/` を使います。
