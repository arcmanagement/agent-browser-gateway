Desktop browsers

Edge and Brave

ABG is built on the Chromium extension APIs used by Chrome, Edge, and Brave. These browsers can connect to the same local Gateway when the extension is installed and a tab is explicitly shared.

Install Smoke checklist Caveats

1. Install

Start the local Gateway app first, then install the extension in the Chromium browser you want to test.

Browser Install path Notes
Microsoft Edge Install from the Chrome Web Store after enabling extensions from other stores, or load extension/dist/ from edge://extensions. Edge reports itself to the Gateway as edge.
Brave Install from the Chrome Web Store, or load extension/dist/ from brave://extensions. Brave reports itself through navigator.brave.isBrave() when available.

2. Smoke checklist

  1. Open the Gateway app and confirm abg status returns local state.
  2. Open Edge or Brave and enable the ABG extension.
  3. Open a normal https:// page and choose Share this tab with agent from the popup.
  4. Run abg tabs --compact and confirm the shared tab appears.
  5. Run abg read t1 --format markdown against the listed tab ref.
  6. Run abg screenshot t1 --out /tmp/abg-edge-brave-smoke.png.
  7. Revoke the tab from the popup or with abg revoke t1, then confirm it disappears from abg tabs --compact.

3. Caveats

  • ABG still uses Chrome extension APIs; Firefox and Safari require separate extension work.
  • Incognito or private windows require the browser's extension settings to allow private-window access.
  • Brave Shields and enterprise Edge policies can block page behavior independently of ABG.
  • All-tabs mode is still intended only for isolated profiles or sandbox browsers.
  • Chrome Web Store dashboard pages cannot be scripted by extensions; use manual submission for store uploads.
