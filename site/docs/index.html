Agent Browser Gateway Docs

Install the local gateway, share Chrome tabs with an AI coding agent, and keep the browser access boundary explicit.

Quickstart Agent skills Access modes CLI commands Safety model Troubleshooting

1. Quickstart

ABG has three local pieces: the Agent Browser Gateway app, the Chrome extension, and the abg CLI. The app listens only on 127.0.0.1; agents talk to the local CLI, not to a hosted browser service.

  1. Install the macOS DMG or Windows ZIP from the download section.
  2. Install Agent Browser Gateway from the Chrome Web Store.
  3. Open the Gateway app, then run abg status.
  4. Open a browser tab and choose Share this tab with agent from the extension popup.
  5. Run abg tabs --compact, then use the listed ref such as t1.
$ abg status
$ abg tabs --compact
$ abg read t1 --format markdown
$ abg screenshot t1 --out page.png

2. Agent skills

ABG ships bundled guidance for Claude Code and Codex so agents know to use the local abg CLI, list only shared tabs, and respect the current tab access mode. 

$ abg install-skill --target both
Target What gets installed
Claude Code agent-browser-gateway skill guidance for the local abg CLI.
Codex The same ABG skill guidance, including manual and all_tabs access mode handling.

Re-run the install command after upgrading ABG. It refreshes only the ABG skill files and does not grant browser access by itself.

3. Tab access modes

ABG is per-tab by default. No browser tab is visible to an agent until the user explicitly shares it from the extension popup.

Mode When to use it Boundary
manual Personal, work, or mixed-use Chrome profiles. Only tabs explicitly shared from the popup. Manual access is revoked on origin change, tab close, or explicit revoke.
all_tabs Sandbox Chrome profiles, test machines, or disposable browser profiles where every tab is intentional agent context. All shareable http, https, and file tabs in that profile after a local opt-in and Chrome permission prompt.

All-tabs mode is off by default. Enabling it requests optional <all_urls> access from Chrome. Disabling it revokes all all-tabs entries and removes that optional host permission.

4. Common CLI commands

The CLI is intentionally scriptable. It prints structured JSON by default, and most commands can target either a numeric tab ID or a short ref such as t1.

Task Command
Inspect gateway state abg status
List shared tabs abg tabs --compact
Read clean page context abg read t1 --format markdown
Capture a screenshot abg screenshot t1 --out page.png
Target an iframe abg frames t1, then abg read t1 --frame @f1
Find and click a button abg find role t1 button click --name "Save"
Type or paste into an editor abg fill t1 --selector "textarea" --value "Draft"
Handle a dialog abg dialog t1, then abg dialog t1 --accept
Inspect downloads abg download t1 --wait --timeout 30000
Wait for a response abg network t1 --wait-response --url "*api/save*" --body
Export a redacted HAR abg har t1 --out /tmp/session.har
Inspect cookies or storage abg state t1 --kind cookies --name "sid*"
Inspect framework signals abg framework t1 --kind web-vitals
Use sandbox-only controls abg sandbox t1 viewport --width 390 --height 844 --mobile
Review local activity abg audit --lines 50

5. Safety model

  • The Gateway binds to 127.0.0.1.
  • The extension declares no default host permissions.
  • Manual tab access is explicit and revocable.
  • Write operations can require a local Chrome approval window.
  • Every read and operation is recorded in a local audit log.
  • ABG does not include analytics, advertising identifiers, or product telemetry.
  • Advanced capabilities are classified as per-tab, sandbox/all-tabs only, self-hosted only, or official non-goals.
  • ABG-operated cloud relay, operator telemetry, and hidden JavaScript execution without explicit user policy are official non-goals.

For details on data handling and Chrome permissions, read the Privacy Policy. For advanced automation boundaries, see ADVANCED_AUTOMATION_POLICY.md.

6. Troubleshooting

No shared tabs

Run abg status first. If the extension is connected but permittedTabCount is 0, open Chrome, select the target tab, and share it from the ABG extension popup.

Incognito tabs

Chrome blocks extensions in incognito windows until they are explicitly allowed. Open the ABG extension settings and enable incognito access before sharing an incognito tab.

All-tabs mode does not stay on

Chrome may have removed the optional host permission. Toggle Share all tabs in this profile again from the popup to re-authorize it.
