# ABG 特許出願書類一式

本ディレクトリは、agent-browser-gateway に係る日本国特許出願のための提出前原稿である。JPO のインターネット出願ソフトに投入する前に、Markdown から JPO 指定の HTML 又は XML 形式へ変換し、出願人情報、識別番号、住所、代表者表示、手数料表示を本人が確定する必要がある。

## 書類一覧

- [01-petition.md](01-petition.md): 特許願。様式第26を Markdown で再現した表紙である。
- [02-specification.md](02-specification.md): 明細書。技術分野、背景技術、課題、手段、効果、実施形態、実施例、符号の説明を含む。
- [03-claims.md](03-claims.md): 特許請求の範囲。システム発明12項、方法発明1項、プログラム発明1項の計14項である。
- [04-abstract.md](04-abstract.md): 要約書。400字以内、選択図は図1である。
- [05-drawings.md](05-drawings.md): 図面一覧。7図の説明と提出用変換方針を記載する。
- [figures/](figures/): Mermaid 図面原稿。SVG 生成用の [build.sh](figures/build.sh) を含む。
- [checklist.md](checklist.md): 出願前チェックリスト、自己レビュー記録、進歩性論点メモである。
- [japanese-text/README.md](japanese-text/README.md): JPO 電子出願ソフト用テキストへの変換メモである。

## 提出手順

1. JPO 公式のインターネット出願ソフトを準備する。JPO 公式説明では、ワープロソフトで作成した HTML 形式の申請書類をインターネット出願ソフトで入力チェック及びフォーマット変換した上で送信する流れである。
2. 電子証明書を取得し、インターネット出願ソフトに登録する。法人出願の場合、ArcManagement 株式会社として利用可能な電子証明書を確認する。
3. 識別番号を取得又は確認する。未取得の場合は JPO の手続に従い初回取得する。
4. 本ディレクトリの Markdown を JPO 指定 HTML 又は XML へ変換する。提出前に書類名、見出し、段落番号、図番、符号を目視確認する。
5. 特許願の TODO 欄を埋める。特に法人住所、代表者表示、識別番号、手数料表示、提出日は未確定である。
6. 出願料を納付する。2026年5月3日時点で、特許出願料は14,000円である。
7. インターネット出願ソフトで入力チェックを実行し、警告又はエラーを解消する。
8. 出願を送信し、出願番号を取得する。
9. 出願後、README 等の公開可能箇所に「Patent Pending (JP 20XX-XXXXXX)」を追記する。出願完了前には追記しない。

## 手数料メモ

- 出願料: 14,000円。
- 出願審査請求料: 138,000円 + 請求項数 x 4,000円。請求項14項の場合は194,000円である。
- 特許料第1年から第3年まで: 毎年4,300円 + 請求項数 x 300円。
- 減免制度: 中小企業等を対象に審査請求料及び特許料の減免措置が設けられている。ArcManagement 株式会社が対象となるかは、審査請求前に本人確認事項である。

## 新規性喪失例外の留意

出願前に発明を公開しないことを原則とする。ABG リポジトリは出願完了まで private のまま維持する。新規性喪失の例外は例外手続であり、海外出願では不利益となる可能性があるため、出願前公開に依存しない運用を採る。

## PCT 国際出願

日本国内出願日から1年以内に PCT 国際出願を検討できる。米国、欧州、中国等での権利化を検討する場合は、国内出願後の事業進捗、競合状況、費用対効果を見て判断する。

## 拒絶理由通知への応答

出願審査請求後、拒絶理由通知が来た場合は、意見書及び手続補正書で応答する。進歩性の主張では、per-tab 明示許可、origin 変更時の自動失効、loopback only Gateway、CDP による host_permissions 不要化、ローカル監査ログ、プラグイン変換の組合せによる技術的効果を中核に置く。

## マイルストーン

- 2026-MM-DD: 日本国特許出願完了。出願番号を本 README に追記する。
- 出願後1年以内: PCT 国際出願の要否を判断する。
- 出願後3年以内: 出願審査請求の要否を判断する。
- 出願公開後: 公開番号及び公開公報の URL を追記する。
