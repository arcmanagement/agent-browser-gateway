# 特許請求の範囲

【請求項1】

ユーザー端末上で動作するブラウザと、当該ユーザー端末上で動作する AI エージェントとを連携させるブラウザAI連携システムであって、

前記ブラウザ上で動作し、タブ単位の共有許可を管理するブラウザ拡張機能と、

前記ユーザー端末上で動作し、前記ブラウザ拡張機能との間でローカル通信を行う Gateway モジュールと、

前記 AI エージェントから呼び出され、前記 Gateway モジュールに操作要求を送信するコマンドラインインターフェースと、

を備え、

前記ブラウザ拡張機能は、ユーザーが特定のタブについて明示的な共有許可操作を行った場合に限り、当該特定のタブを共有許可済みタブとして前記 Gateway モジュールに登録し、

前記 Gateway モジュールは、前記コマンドラインインターフェースから受信した前記操作要求が前記共有許可済みタブを対象とする場合に限り、当該操作要求を前記ブラウザ拡張機能に転送し、

前記ブラウザ拡張機能は、前記共有許可済みタブの現在の origin が、前記明示的な共有許可操作の時点で記録された許可時 origin と異なる origin へ変更されたことを検知した場合に、当該共有許可済みタブの共有許可を失効させる、

ことを特徴とするシステム。

【請求項2】

請求項1に記載のシステムにおいて、

前記ブラウザ拡張機能は、前記共有許可済みタブが閉じられたことを検知した場合に、当該共有許可済みタブの共有許可を失効させる、

ことを特徴とするシステム。

【請求項3】

請求項1に記載のシステムにおいて、

前記ブラウザ拡張機能又は前記コマンドラインインターフェースは、ユーザーによる明示的な取消操作を受け付け、

前記 Gateway モジュールは、前記取消操作に応じて対象タブの共有許可を失効させる失効要求を前記ブラウザ拡張機能に送信する、

ことを特徴とするシステム。

【請求項4】

請求項1に記載のシステムにおいて、

前記 Gateway モジュールは、共有許可の付与、共有許可の失効、読み取り操作、及び書き込み操作を含む操作履歴を、前記ユーザー端末上の監査ログに JSONL 形式で追記する監査ログ記録部を備え、

前記監査ログ記録部は、前記監査ログを格納するディレクトリ及びファイルのアクセス権限を、前記ユーザー端末の所有者ユーザーのみが読み書き可能な権限に設定する、

ことを特徴とするシステム。

【請求項5】

請求項1に記載のシステムにおいて、

前記 Gateway モジュールは、前記ブラウザ拡張機能との通信待受をループバックインターフェースに限定し、

前記ブラウザ拡張機能との WebSocket 接続要求について、当該接続要求の Origin がブラウザ拡張機能 origin であることを検証し、通常の Web ページ origin、file origin、null origin、欠落 Origin、又はパス、クエリ、フラグメント若しくはユーザー情報を含む Origin からの接続要求を拒否する、

ことを特徴とするシステム。

【請求項6】

請求項1に記載のシステムにおいて、

前記ブラウザ拡張機能は、Manifest V3 形式で構成され、全 URL を対象とする host_permissions を有さず、ユーザー操作に基づく activeTab 権限により共有許可対象のタブに対するアクセスを取得する、

ことを特徴とするシステム。

【請求項7】

請求項1に記載のシステムにおいて、

前記ブラウザ拡張機能は、読み取り操作については前記共有許可済みタブであることを条件として実行し、クリック、入力、キー送信、スクロール、ナビゲーション、ドラッグ、ファイル添付、及び一時的な DOM 差し替えの少なくとも一つを含む書き込み操作については、当該書き込み操作の内容をユーザーに提示し、ユーザーの承認を受けた場合に限り実行する、

ことを特徴とするシステム。

【請求項8】

請求項1に記載のシステムにおいて、

前記ブラウザ拡張機能は、Chrome DevTools Protocol を用いて、DOM 読み取り、スクリーンショット取得、コンソールログ取得、ネットワークログ取得、座標クリック、スクロール、ドラッグ、キー送信、ファイル入力要素へのファイル設定、及び共有許可済みタブ上での注釈レイヤ実行の少なくとも一つを実行する、

ことを特徴とするシステム。

【請求項9】

請求項1に記載のシステムにおいて、

前記 Gateway モジュールは、前記ブラウザ拡張機能から受信したタブ内容を、前記 AI エージェントへ返送する前に、同一プロセス内、又は別プロセスで動作する外部スクリプト若しくは実行ファイルにより変換する変換実行部を備える、

ことを特徴とするシステム。

【請求項10】

請求項1に記載のシステムにおいて、

前記コマンドラインインターフェースは、共有許可済みタブの一覧取得、タブ内容の読み取り、スクリーンショット取得、要素説明、テーブル抽出、ネットワークログ取得、注釈レイヤの開始、停止、消去及び注釈一覧取得、クリック、入力、キー送信、ナビゲーション、スクロール、ドラッグ、ファイル添付、一時的な DOM 差し替え、待機、共有許可の取消し、及び監査ログの取得の少なくとも一つを、シェルコマンドとして前記 AI エージェントに提供する、

ことを特徴とするシステム。

【請求項11】

請求項1に記載のシステムにおいて、

前記 Gateway モジュールは、ドメイン条件及び変換名を含むプラグイン定義を読み込み、前記共有許可済みタブの URL が前記ドメイン条件に合致する場合に、汎用変換より前に当該ドメイン条件に対応する変換処理を実行する、

ことを特徴とするシステム。

【請求項12】

請求項1に記載のシステムにおいて、

前記コマンドラインインターフェースは、共有許可済みタブに対する複数の操作をフローとして記録し、前記フローを実行前に表示するドライラン処理と、前記フローを共有許可済みタブに対して再生する再生処理とを提供し、反復操作検証又はモンキーテスト支援に用いられる操作列を生成及び再実行可能にする、

ことを特徴とするシステム。

【請求項13】

請求項1に記載のシステムにおいて、

前記ブラウザ拡張機能は、前記共有許可済みタブ上に注釈レイヤを描画し、

前記注釈レイヤは、ユーザーによる領域指定、ユーザーによるテキスト選択、及び前記コマンドラインインターフェースからの注釈追加要求の少なくとも一つを注釈入力として受け付け、当該注釈入力に対応する番号及びコメントを前記共有許可済みタブ上に視覚的に表示する、

ことを特徴とするシステム。

【請求項14】

請求項13に記載のシステムにおいて、

前記ブラウザ拡張機能は、前記注釈入力が領域指定である場合に、安定した DOM セレクタに対応する対象要素を推定できるときは DOM 注釈として分類し、当該対象要素を推定できないときはスクリーンショット領域注釈として分類し、

前記注釈入力がテキスト選択である場合に、選択文字列及び当該選択文字列を再特定するためのテキストアンカーを含むテキスト注釈として分類し、

前記 DOM 注釈、前記スクリーンショット領域注釈、又は前記テキスト注釈を、ビューポート座標、ページ座標、コメント、作成時刻、URL、タイトル、及び対象要素のセレクタ、文字列又はスタイル情報の少なくとも一つを含む注釈データとして保持する、

ことを特徴とするシステム。

【請求項15】

請求項13に記載のシステムにおいて、

前記ブラウザ拡張機能は、前記注釈レイヤを実行するにあたり、ブラウザ拡張機能 API によるスクリプト実行を試行し、当該スクリプト実行がブラウザの host permission 挙動により拒否された場合に、デバッガ接続を確立したうえで Chrome DevTools Protocol の Runtime.evaluate により前記注釈レイヤを実行する、

ことを特徴とするシステム。

【請求項16】

ユーザー端末上で動作するブラウザと、当該ユーザー端末上で動作する AI エージェントとを連携させる方法であって、

前記ブラウザ拡張機能が、前記操作要求に応じて前記対象タブに対する読み取り又は操作を実行し、又は前記注釈要求に応じて前記対象タブ上に注釈レイヤを描画するステップと、

前記ブラウザ拡張機能が、前記対象タブの現在の origin が前記許可時 origin と異なる origin へ変更されたことを検知した場合に、当該対象タブの共有許可を失効させるステップと、

を含むことを特徴とする方法。

【請求項17】

請求項16に記載の方法において、

前記注釈レイヤを描画するステップは、ユーザーによる領域指定を DOM 注釈又はスクリーンショット領域注釈に分類するステップと、ユーザーによるテキスト選択をテキスト注釈に分類するステップと、前記 DOM 注釈、前記スクリーンショット領域注釈、又は前記テキスト注釈を前記コマンドラインインターフェースへ返送する注釈データとして保持するステップとを含む、

ことを特徴とする方法。
