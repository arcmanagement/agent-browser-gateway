## Pass 3 自己レビュー記録

### 1周目: 新規性

- 請求項1は、単なるブラウザ操作又は単なる AI 連携ではなく、タブ単位明示許可、Gateway 経由の操作要求限定転送、origin 変更時自動失効を同一構成内に入れた。
- 請求項4は、監査ログの存在だけでなく、所有者ユーザーのみに限定される保存権限まで含め、業務利用時の操作追跡構成を明確化した。
- 請求項5は、loopback only に加えて WebSocket Origin 検証を含め、通常 Web ページからローカル Gateway へ接続される攻撃面を先行技術との差分として明確化した。
- 請求項6は Manifest V3、全 URL host_permissions なし、activeTab による共有許可対象タブアクセスを明記し、全 URL 一括許可型拡張との差を明確化した。
- 請求項8は CDP 単独では既知であるため、請求項1の共有許可済みタブ限定構成に従属させ、注釈レイヤ実行及びファイル設定まで含めた。
- 請求項13から15は、注釈レイヤ、DOM/screenshot/text 自動分類、及び Runtime.evaluate フォールバックを組み合わせ、単なるスクリーンショット注釈との差を出した。
- 請求項16から18は、システム構成を方法及びプログラムとしても保護し、注釈要求及び Origin 検証を方法・プログラム側にも入れた。

### 2周目: 進歩性

- prior art 1.1から1.3の商用ブラウザ AI 連携は、バックエンド通信又はブラウザ本体機能を前提とするため、loopback only、CLI 汎用インターフェース、ローカル監査ログ、WebSocket Origin 検証の組合せを前面に出した。
- prior art 1.4から1.8の自動化フレームワークは、専用ブラウザ又はテスト用途が中心であるため、普段使いブラウザの共有許可済みタブのみを対象とし、注釈レイヤでユーザーが対象を確認できる点を補強した。
- prior art 1.9から1.13の拡張機能データ漏洩事案は、全 URL 権限及び外部送信リスクの背景として位置付け、host_permissions なし、外部中継非送信、owner-only 監査ログを効果に結び付けた。
- annotation overlay は単なる画像注釈ではなく、DOM セレクタ、スクリーンショット領域、テキストアンカーを分類して AI エージェントに構造化返送する点を進歩性論点にした。
- ブラウザ相当環境向け注釈対応は、外部注釈データの取り込みではなく、host permission 挙動が異なる環境で CDP `Runtime.evaluate` にフォールバックする相互運用性として整理した。
- token economy は特許性の中核要件ではなく、実施例及び効果の補強として位置付けた。

## 請求項別進歩性論点メモ

- 請求項1: per-tab 明示許可、操作要求限定転送、origin 変更時自動失効の組合せが中核である。
- 請求項2: タブ閉鎖時失効は単独では弱いが、請求項1の許可ライフサイクル補完要素である。
- 請求項3: 明示的取消しは単独では弱いが、popup と CLI の双方から同じ許可状態を失効できる点に実施価値がある。
- 請求項4: ローカル監査ログに加えて owner-only 権限を明記し、AI エージェント操作の事後追跡と端末内保護を両立する。
- 請求項5: loopback only と WebSocket Origin 検証の組合せにより、通常 Web ページからローカル Gateway へ接続される経路を遮断する。
- 請求項6: Manifest V3、全 URL host_permissions なし、activeTab の組合せは、全 URL 一括許可型拡張との差別化要素である。
- 請求項7: 書き込み操作承認は、読み取り共有許可とは別の安全境界を提供し、replace/upload/navigate 等の高リスク操作を明示対象化する。
- 請求項8: CDP 利用は既知であるが、共有許可済みタブ限定、host_permissions 不要化、注釈レイヤ実行を組み合わせる点に意味がある。
- 請求項9: 同一プロセス内 JavaScriptCore と別プロセス plugin の双方を包含し、変換処理を Gateway 側に集約する点が実装と一致する。
- 請求項10: CLI を universal AI interface とし、annotate/replace まで含めることで特定 AI サービス又は MCP 実装への依存を避ける。
- 請求項11: domain glob と transform 名を用いて汎用変換より前に per-domain 変換を選択する点が Notion 実装と一致する。
- 請求項12: 記録、ドライラン、再生により、AI 由来の操作列を監査可能かつ再実行可能にする点が反復検証上の差分である。
- 請求項13: 共有許可済みタブに限定して注釈レイヤを描画し、ユーザーの指示対象を番号及びコメント付きで視覚化する点が agent UX 上の差分である。
- 請求項14: DOM 注釈、スクリーンショット領域注釈、テキスト注釈を自動分類し、selector、rect、textAnchor 等の構造化データとして返す点が単なる画像注釈との差分である。
- 請求項15: host permission 挙動でスクリプト実行が拒否される環境において CDP `Runtime.evaluate` へフォールバックする点がブラウザ相当環境との相互運用性を補強する。
- 請求項16: 請求項1、5、13の主要処理を方法発明として保護する。
- 請求項17: 注釈分類及び注釈データ保持の方法処理を、方法発明の従属項として補強する。
- 請求項18: 請求項16相当の処理をコンピュータに実行させるプログラムとして保護する。
