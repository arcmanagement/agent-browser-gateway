# Microsoft Store assets

`microsoft-store-screenshot-1366x768.png` is the English (United States)
desktop screenshot for Partner Center. Its browser frame uses Windows-style
window controls. Do not replace them with the macOS red, yellow, and green
traffic-light controls; Microsoft rejected that metadata under policy
10.1.1.3 (Inaccurate Representation) on August 24, 2026.

Before uploading a replacement, verify that the PNG is exactly `1366 x 768`
and does not show UI or devices from another platform.
